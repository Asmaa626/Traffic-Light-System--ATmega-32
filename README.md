# 🚦 Traffic Light System using ATmega32

## 📖 Project Overview
This project simulates a traffic light system using ATmega32 microcontroller to control traffic between two directions.

## 💡 Idea
The system consists of four traffic signals (two opposite directions), connected in series. When one direction is active, the opposite direction is stopped.

## ⚙️ Components Used
- ATmega32 Microcontroller
- LEDs (Red, Yellow, Green)
- 7-Segment Display
- LCD (I2C)
- DHT11 Sensor

## 🔁 System Operation
- Green LED works from 37 to 3 seconds  
- Last 3 seconds → blinking (alert)  
- Yellow LED works for 3 seconds  
- Red LED works opposite to green  

## 🧠 Control
The ATmega32 controls all operations including timing, signal switching, and sensor reading.

## 🖥️ Simulation
The circuit is simulated using Proteus software.
